# Fase 01 — Fundação funcional

Leia `GEMINI.md` e documentos da arquitetura. Implemente um monorepo buildável em TypeScript (Next.js + NestJS + PostgreSQL), com workspaces, design system pt-BR, autenticação, escopo de dados, autorização API, layout administrativo, navegação por perfil, página inicial com dados vazios reais, migração base, healthcheck e audit log. Não crie dashboards com dados falsos. Implemente testes unitários e E2E com 3 perfis (Financeiro Disk, Produtor, SAC), inclusive tentativa de acesso cruzado a evento. Dê atenção especial à navegação: cada submenu renderizado deve apontar para rota existente; para módulos não implementados ainda, não exibir ação operacional enganosa. Documente boot local, variáveis, build e Preview. Entregue `docs/execucao/FASE-01.md` com os testes executados e bloqueios reais. Não tocar em produção.
